共同設定（先讀這段）
----------------------------------------------------------------
- A 冷水基準（題目原設定）：液冷供水跟著濕球溫度走，約 25–34 °C（濕球 + 6 K）。
- B 溫水基準（對照組）：液冷供水固定 40 °C，代表機房本來就採溫水冷卻。
- 液冷回水溫度 T_ret：把液冷回水拉高到這個溫度，拿去驅動吸附式冰機。供水 = T_ret − 10 K。
- k_leak：冷卻液每升溫 1 K，液冷 IT 功率增加的比例。基準值 0.15 %/K，是全模型最不確定的參數。
- 吸附機要 ≥50 °C 熱水才能運轉（T_ret ≥ 52 °C），所以很多曲線在 51–52 °C 有一個「跳階」：
  吸附機從不能運轉跳到能運轉。這是模型設定造成的，不是計算錯誤。
- 紅色點線 = 供水 45 °C 上限（T_ret 55 °C），超過這條線就超出 W45 / 廠商溫水冷卻範圍。
- 氣象資料是用臺南月平均值合成的 8760 小時資料，不是實測值。


fig1_溫度vs總耗電.png — 核心圖：回水溫度要拉到多高？
----------------------------------------------------------------
上排是 A，下排是 B；左右欄看的東西不同。
左欄：兩情境的年平均總耗電（MW）
  - 藍色水平線 = Baseline（不改冷卻方式）。橘線 = 導入吸附式冰機後的耗電。
  - 橘線在藍線「下方」才代表省電。灰色虛線 = 損益兩平溫度，右下角方框列出數值。
  - A：橘線全程在藍線上方 → 不管回水拉到幾度都比較耗電，沒有損益兩平點。
  - B：52–62 °C 之間橘線在藍線下方 → 這段是「划算的回水溫度區間」。
    （50.0、51.6 °C 兩個交點是跳階造成的，實際有意義的上限是 62.2 °C。）
右欄：節能分解（kW），解釋左欄「為什麼」會這樣
  - 綠線 = 電動冰機省下的電 Q_air/COP_e（正值，好處）。
  - 紅線 = −ΔP_IT，晶片升溫多耗的電（負值，代價）。溫度越高紅線越往下。
  - 紫線 = −ΔP_aux，吸附機的泵、冷卻塔、本體多耗的電（負值，代價）。
  - 黑粗線 = 淨節省 = 綠 + 紅 + 紫；方框標出最大值。
  - 綠色虛線（右軸）= 吸附機能供應的冷量占氣冷負載的比例。
看圖重點：
  - 綠線最多只到約 260 kW，然後就飽和（覆蓋率接近 100%）；紅線卻會一直往下掉。
    所以最佳點會落在「吸附機剛能啟動的溫度」附近（B 是 52 °C），溫度不是越高越好。
  - A 的紅線從 40 °C 就開始往下，因為基準供水很低，回水一拉高晶片就升溫十幾度。


fig2_敏感度.png — 結論對 k_leak 和基準供水溫度有多敏感？
----------------------------------------------------------------
三張圖的縱軸都是年平均淨節省（kW），在 0 以上才代表省電。
(a) A 冷水基準，不同 k_leak：只有最上面那條 0.05 %/K 跑到 0 以上。
    → A 情境要晶片幾乎不受溫度影響（≤0.05 %/K）才值得做。
(b) B 溫水基準，不同 k_leak：每條線和 0 的交點，就是那個 k_leak 下划算區間的上限。
    0.05 %/K 時 52–70 °C 都划算；0.25 %/K 只剩 52–55 °C；0.50 %/K 時幾乎沒有。
(c) 固定 k_leak = 0.15 %/K，只改 Baseline 的供水溫度（藍 A／橘 35 °C／紅 B 40 °C）：
    基準供水越高，曲線越往上。→ 吸附式冰機適合「本來就跑溫水」的機房。
看圖重點：與其問「回水要幾度」，更該先問「基準供水幾度、晶片 k_leak 多少」。


fig3_NPV地圖.png — 經濟面：容量 × 回水溫度的組合
----------------------------------------------------------------
- 橫軸 = 全年固定的回水溫度；縱軸 = 吸附機額定容量 / 氣冷負載（0.5×～3×）。
- 顏色 = 15 年 NPV（折現率 7%）：藍色是賺錢，紅色是賠錢，白色接近打平。
- ★ = 整張圖 NPV 最大的組合；如果有 NPV = 0 的等高線，圖上會畫出黑線。
看圖重點：
  - A、B 整張圖都是紅的 → 在目前的成本假設下，沒有任何組合能回本。
  - ★ 都落在最小容量（0.5×）→ 吸附機買越多賠越多，每多買 1 kW 省下的電不夠付設備費。
  - B 在 52 °C 附近顏色最淺（最接近打平），和 fig1 的最佳溫度一致。


fig4_現金流量圖.png — 工程經濟的現金流量圖
----------------------------------------------------------------
上圖 (a) 是 A 的最佳方案，下圖 (b) 是 B 的最佳方案（兩者都是「逐日動態回水」策略）。
- 箭頭：第 0 年往下的紅箭頭 = 投資額（CAPEX）；之後每年往上的綠箭頭 = 淨收入
  （省電費 + 省水費 − 維護費）；往下的紅箭頭 = 那年反而淨支出。旁邊數字單位為百萬元。
- 藍色實線 = 累積折現現金流，回到 0 以上的那一年就是折現回收年限。
- 灰色虛線 = 累積未折現現金流（不考慮貨幣時間價值）。
- 標題列出 CAPEX、年節電、NPV、IRR、回收年限。
看圖重點：
  - A：吸附機一整年都沒有啟用（啟用 0 天），每年只付維護費，所以每年都是小紅箭頭。
  - B：每年淨收入約 0.5–0.7 百萬元，相對 33 百萬的投資太小，15 年後累積還是 −28 百萬左右。
  - 年度箭頭看起來很短，是因為和第 0 年投資額放在同一個比例尺上，這本身就是結論。


fig5_NPV龍捲風.png — 哪個參數最影響賺賠？
----------------------------------------------------------------
- 以 B 的最佳方案為基準（中間黑色直線，NPV 約 −27.8 百萬），一次只改一個參數。
- 每條長條的兩端 = 參數取左邊值 / 右邊值時的 NPV；紅色是前值，綠色是後值。
- 長條越長 = 越敏感，已經由上往下排序。灰色虛線 = NPV 0（回本線）。
看圖重點：
  - 前三名：設備單價 > k_leak > 吸附機最低驅動溫度。電價、折現率、碳價的影響都很小。
  - 就算每個參數都取最樂觀的值，也沒有一條長條碰到灰色虛線。
    → 要回本必須多個條件同時成立，例如設備便宜很多、而且 k_leak 很低。
  - summary.txt 的「損益兩平投資額」：B 情境安裝後單價要壓到約 NT$3,300/kW 才打平，
    目前假設 NT$25,600/kW。


fig6_逐時年度.png — 一整年怎麼運轉？（B 溫水基準、逐日動態策略）
----------------------------------------------------------------
上：合成的逐時濕球溫度，冬天約 10–20 °C，夏天約 25–30 °C。
中：吸附機每天的平均冷量（綠線）和氣冷負載 1,800 kW（黑虛線）；
    橘點（右軸）= 當天選用的回水溫度，沒有點的日子就是不啟用、維持 Baseline。
下：每天平均總耗電，藍 = Baseline，橘 = 動態策略。
看圖重點：
  - 吸附機主要在 10 月到隔年 4 月運轉；5–9 月濕球高、冷卻水溫高，吸附機出力掉到接近 0，
    策略就選擇不啟用。全年約啟用 238 天。
  - 有啟用的日子幾乎都選 52 °C（剛好能驅動的最低溫度），再次印證「溫度不是越高越好」。
  - 冬天橘線比藍線低約 40–50 kW，夏天兩線重疊，平均下來全年只省約 23 kW
    （這是容量 0.5× 的經濟最佳點；容量 1.5× 可省約 77 kW，但投資更高）。


一句話總結
----------------------------------------------------------------
在題目設定（A 冷水基準）下，回水拉高造成的晶片耗電大於冰機省下的電，沒有划算的溫度區間；
若機房本來就跑溫水（B），52–62 °C 能省電，但最多約 100 kW，以目前設備價格 15 年內回不了本。
最該優先確認的兩個數字：晶片的 k_leak，以及吸附式冰機的實際報價。
